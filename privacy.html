Privacy Policy

Brand Examiner Pipeline · Effective October 4, 2026

Who uses this app

Brand Examiner Pipeline is a private, single-user tool operated by The Brand Examiner channel. It is used only with the channel's own Google account. It is not available to the public.

What Google data it accesses

  • Google Drive: to upload and replace the channel's own production files (draft videos, audio, images, documents) in the channel's own Drive folders, and to read those files for review.
  • YouTube Data and YouTube Analytics (if enabled): to upload and manage the channel's own videos and to read the channel's own performance metrics.

How the data is used

Data is used only to produce, store, publish, and measure the channel's own videos. It is not sold, rented, shared with third parties, or used for advertising. It is not used to train machine-learning models.

Storage and security

Files stay in the channel's own Google Drive and YouTube account. Access credentials are stored as encrypted secrets in the channel's private GitHub repository and are never published. Access can be revoked at any time from the Google account's security settings.

Google API Services User Data Policy

Brand Examiner Pipeline's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
